# 🍏 Интеграция с iOS: Быстрые команды (Shortcuts) и Apple Health

Инструкция по настройке автоматизации на вашем **iPhone**, **Apple Watch** и кнопке действия (**Action Button** на iPhone 15 Pro / 16).

---

## ⚡ 1. Быстрая диктовка голосом («Fast Dictation»)

Позволяет запускать голосового секретаря в **1 касание**:
- С экрана блокировки (Lock Screen Widget).
- Нажатием кнопки действия (**Action Button**).
- Через Siri: *«Привет Siri, Секретарь»*.

### 📱 Пошаговая инструкция по созданию команды:

1. Откройте стандартное приложение **«Быстрые команды» (Shortcuts)** на iPhone.
2. Нажмите **`+`** в правом верхнем углу, чтобы создать новую команду.
3. Назовите команду: **`Секретарь`** (или `My Secretary`).
4. По очереди добавьте следующие действия:

#### Действие 1: «Диктовать текст» (Dictate Text)
- Язык: **Русский** (или Украинский).
- Остановка прослушивания: **После паузы** (After pause).

#### Действие 2: «Получить содержимое URL» (Get Contents of URL)
- **URL**: `http://<IP_ВАШЕГО_СЕРВЕРА>:8000/api/v1/gemini/process` *(или защищённый адрес через Cloudflare/ngrok)*.
- **Метод (Method)**: `POST`.
- **Заголовки (Headers)**:
  - `Content-Type`: `application/json`
  - `X-Secret-Key`: `<ВАШ_SECRET_KEY_ИЗ_ENV>`
- **Тело запроса (Request Body)**: `JSON`
  - Добавить новое поле:
    - Ключ: `text`
    - Тип: `Текст`
    - Значение: выберите переменную **«Продиктованный текст»** (Dictated Text).

#### Действие 3: «Получить значение из словаря» (Get Dictionary Value)
- Ключ: `reply`
- Источник: **Содержимое URL** (Contents of URL).

#### Действие 4: «Произнести текст» (Speak Text)
- Текст: выберите результат из Действия 3 (**Значение из словаря**).
- Скорость и голос: Siri (Русский / Украинский).

#### *(Опционально)* Действие 5: «Показать уведомление» (Show Notification)
- Текст: результат ответа Секретаря.

---

### 🔘 Назначение на Action Button (кнопку действия):
1. Перейдите в **«Настройки» iOS** -> **«Кнопка действия» (Action Button)**.
2. Пролистайте до пункта **«Быстрая команда» (Shortcut)**.
3. Выберите команду **«Секретарь»**.
4. 🎯 Готово! Зажали кнопку на торце iPhone -> сказали: *«Купил обед 250 гривен и в список покупок минералку»* -> iPhone голосом подтверждает выполнение!

## 🏃 2. Ежедневная авто-синхронизация Apple Health («Health Auto-Sync»)

Каждый вечер в **23:00** iPhone автоматически считывает показатели вашего шагомера, пройденную дистанцию, сожжённые калории, этажи и тренировки (включая горнолыжные спуски) и отправляет их в модуль `Fitness` Секретаря.

### 📱 Создание автоматизации:

1. В приложении **«Быстрые команды»** перейдите на вкладку **«Автоматизация»** (Automation внизу по центру).
2. Нажмите **`+`** (или «Новая автоматизация»).
3. Выберите триггер: **«Время суток»** (Time of Day):
   - Время: **23:00**.
   - Повторение: **Ежедневно**.
   - Режим запуска: **«Немедленный запуск»** (Run Immediately) без запроса подтверждения.
4. Нажмите **«Далее»** -> **«Новая пустая автоматизация»**.

### 🧩 Действия внутри автоматизации:

#### Шаг 1: Получение шагов за сегодня
- Добавьте действие: **«Найти образцы здоровья» (Find Health Samples)**:
  - Тип: **Шаги (Steps)**.
  - Фильтр: Дата начала — **Сегодня**.
  - Группировать по: **Дням**, операция: **Сумма**.

#### Шаг 2: Получение дистанции
- Действие: **«Найти образцы здоровья»**:
  - Тип: **Дистанция ходьбы и бега (Walking + Running Distance)**.
  - Фильтр: Дата начала — **Сегодня**.
  - Группировать по: **Дням**, операция: **Сумма**.

#### Шаг 3: Получение этажей (подъемов)
- Действие: **«Найти образцы здоровья»**:
  - Тип: **Пройдено лестничных пролетов (Flights Climbed)**.
  - Фильтр: Дата начала — **Сегодня**, операция: **Сумма**.

#### Шаг 4: Получение активных калорий
- Действие: **«Найти образцы здоровья»**:
  - Тип: **Активная энергия (Active Energy / Calories)**.
  - Фильтр: Дата начала — **Сегодня**, операция: **Сумма**.

#### Шаг 5: Формирование словаря JSON
- Действие: **«Словарь» (Dictionary)**:
  - `steps` (Число) = Шаги из Шага 1.
  - `distance_km` (Число) = Дистанция из Шага 2.
  - `flights_climbed` (Число) = Пролеты из Шага 3.
  - `calories` (Число) = Калории из Шага 4.
  - `workout_type` (Текст) = `general`

#### Шаг 6: Отправка на сервер
- Действие: **«Получить содержимое URL» (Get Contents of URL)**:
  - **URL**: `http://<IP_ВАШЕГО_СЕРВЕРА>:8000/api/v1/fitness/sync`
  - **Метод**: `POST`
  - **Заголовки (Headers)**:
    - `Content-Type`: `application/json`
    - `X-Secret-Key`: `<ВАШ_SECRET_KEY>`
  - **Тело запроса (Request Body)**: `JSON` -> выберите **Словарь** из Шага 5.

#### *(Опционально)* Шаг 7: Горнолыжные тренировки (Skiing)
Если вы катаетесь на лыжах в Буковеле или Альпах (используя Apple Watch или приложение вроде Slopes):
- В теле запроса можно передать:
  ```json
  {
    "workout_type": "skiing",
    "distance_km": 34.5,
    "workout_details": {
      "descents": 14,
      "max_speed_kmh": 68.4,
      "resort": "Буковель"
    }
  }
  ```
- Секретарь по запросу голосом: *«Покажи лыжные спуски»* выдаст полную статистику по дням и скоростям!

---

## 🔒 Безопасность соединения
Все запросы защищены заголовком `X-Secret-Key`. При использовании за пределами домашней сети рекомендуется использовать защищенный туннель (Cloudflare Tunnel с бесплатным доменом или Tailscale VPN).

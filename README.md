# 🎙️ Мой Секретарь (My Secretary)

Интеллектуальный автономный персональный AI-секретарь на **FastAPI**, **Google Gemini** и **PWA** для управления личной жизнью: финансами, покупками, задачами и медиа-заметками.

---

## 🌟 Основные возможности

1. **Голосовой и текстовый ввод в один клик:**
   - Большая кнопка микрофона с анимацией волны и таймером записи.
   - Поддержка распознавания естественной речи через **Gemini 2.0 / 1.5 Flash**.
   - Умное разделение комбинированных запросов (например: *«Купил кофе за 350р, запиши купить молоко и напомни завтра в 10 позвонить врачу»* создаст запись в финансах, список покупок и задачу одновременно!).
2. **4 ключевых модуля:**
   - 💰 **Финансы:** Учёт расходов и доходов, категории, валюты, аналитика за сегодня и месяц.
   - 🛒 **Список покупок:** Быстрое добавление, вычеркивание в один клик, групповая очистка, а также **кнопка экспорта/отправки в Telegram** одним кликом.
   - ✅ **Задачи:** Дедлайны, приоритеты (High/Medium/Low), статусы выполнения, категории.
   - 🎬 **Медиа и заметки:** Фильмы, сериалы, книги, подкасты, статьи и ссылки со статусами и отзывами.
3. **Модули «Домашний уют и Авто» (Step 2):**
   - 📦 **«Где что лежит» (Инвентарь):** Хранение вещей с точным описанием мест, нечеткий (fuzzy) поиск по вопросу «Где лежит...?».
   - 🚗 **«Авто и Гараж»:** Фиксация пробега, расчет остатка км до следующего ТО / замены масла, контроль даты и статуса страховки.
   - 💡 **«Счетчики коммунальных»:** Учет электроэнергии, воды и газа с автоматическим расчетом дельты (расхода) по сравнению с предыдущими показаниями.
   - 🔍 **Google Search Agent:** Поиск актуальной информации в интернете через Gemini native search grounding (`POST /api/v1/agent/ask`).
   - 🎙️ **Расширенный Gemini Voice Router:** Классификация запросов по 9 намерениям с делегированием поиска агенту и запросов активности («Сколько шагов я сегодня прошел?», «Покажи лыжные спуски»).
4. **Спорт, Бронирования и Google Drive 5TB (Step 3):**
   - 🍏 **Фитнес и Apple Health (`app/modules/fitness/`):** Ежедневная синхронизация шагов, дистанции, этажей, калорий с iPhone/Apple Watch. Фиксация горнолыжных спусков (Буковель/горы: спуски, макс. скорость, км).
   - 🏨 **Гостеприимство и Апартаменты (`app/modules/hospitality/`):** Спящий модуль бронирования с авторасчетом стоимости діб, передоплат и остатка (активируется через `ENABLE_HOSPITALITY=True`).
   - ☁️ **Google Drive 5TB Backup (`app/core/gdrive_backup.py`):** 256-битный шифрованный архив базы (`.sqlite.enc`) с автовыгрузкой в Google Drive (`Secretary_AI_Backups`) каждую ночь в 03:00 или по кнопке.
   - 📱 **Гайд по iOS Shortcuts:** Инструкция в [`docs/IOS_SHORTCUTS.md`](docs/IOS_SHORTCUTS.md) по настройке Action Button и автосинхронизации здоровья в 23:00.
5. **Безопасность и приватность:**
   - **Шифрование базы SQLite (Fernet):** Чувствительные текстовые поля шифруются «на лету» 256-битным ключом.
   - **Защита эндпоинтов (SECRET_KEY):** Авторизация по заголовку `X-Secret-Key`, `Bearer` или query-параметру.
6. **Мобильный PWA-интерфейс:**
   - Mobile-first адаптивный интерфейс с глубокой тёмной темой в стиле iOS.
   - Оффлайн-кэширование (Service Worker) и баннер при отсутствии связи.
   - Возможность добавления на главный экран iPhone/iPad или Android как нативное приложение.

## 🚀 Быстрый старт

### Шаг 1. Создание виртуального окружения и установка

```bash
# Перейдите в папку проекта
cd /Users/vadymvoitusik/.gemini/antigravity/scratch/my-secretary

# 1. Создать виртуальное окружение
python3 -m venv venv
source venv/bin/activate  # (для Windows: venv\Scripts\activate)

# 2. Установить зависимости
pip install -r requirements.txt
```

---

### Шаг 2. Настройка файла `.env`

Создайте файл `.env` в корне проекта на основе шаблона `.env.example`:

```bash
cp .env.example .env
```

Заполните три ключевых параметра:

1. **`GEMINI_API_KEY`**:
   - Получите бесплатный API ключ в [Google AI Studio](https://aistudio.google.com/app/apikey).
2. **`SECRET_KEY`**:
   - Придумайте любой надёжный пароль (например: `my_super_secret_key_2026`). Он защитит ваш сервер от посторонних.
3. **`ENCRYPTION_KEY`**:
   - Сгенерируйте 32-байтный ключ Fernet для шифрования базы данных одной командой в терминале:
   ```bash
   python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
   ```
   Скопируйте вывод и вставьте в `.env`.

Пример итогового `.env`:
```env
GEMINI_API_KEY=AIzaSy...
SECRET_KEY=my_super_secret_key_2026
ENCRYPTION_KEY=gAAAAABl...==
DATABASE_URL=sqlite:///./secretary.db
HOST=0.0.0.0
PORT=8000
```

---

### Шаг 3. Запуск сервера

Запустите сервер FastAPI:

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Откройте в браузере: **[http://localhost:8000](http://localhost:8000)**.
Перед вами откроется дашборд «Секретаря». В верхнем правом углу нажмите на шестерёнку ⚙️ и введите ваш `SECRET_KEY`, чтобы браузер сохранил его для всех запросов.

## 📱 Настройка на iPhone / iPad (iOS)

### Вариант 1: Установка как PWA на Домашний экран

1. Откройте Safari на вашем iPhone и перейдите по адресу сервера (например, по локальному IP `http://192.168.1.XX:8000` или через туннель Cloudflare / ngrok / домен с HTTPS).
2. Нажмите кнопку **«Поделиться»** (иконка квадрата со стрелкой вверх внизу экрана Safari).
3. Прокрутите вниз и выберите **«На экран "Домой"»** (Add to Home Screen).
4. Нажмите **«Добавить»**. На домашнем экране появится иконка «Секретарь», открывающаяся на весь экран без рамок браузера.
5. Откройте приложение, зайдите в настройки (шестеренка ⚙️) и укажите `SECRET_KEY`.

---

### Вариант 2: Голосовой ввод через Siri или Action Button (Apple Shortcuts)

Вы можете отправлять голосовые команды или текст «Секретарю» прямо через голосовой ввод Siri или нажатием на **Action Button** (кнопку действия на iPhone 15 Pro / 16)!

#### Создание команды в приложении «Быстрые команды» (Shortcuts):

1. Откройте приложение **«Команды»** на iPhone и нажмите **«+»** (создать новую).
2. Назовите команду, например, **«Секретарь»**.
3. Добавьте действие: **«Диктовать текст»** (Dictate Text) — язык: Русский.
4. Добавьте действие: **«Получить содержимое URL»** (Get Contents of URL):
   - **URL**: `http://<ваш-ip-или-домен>:8000/api/process`
   - **Метод**: `POST`
   - **Заголовки (Headers)**:
     - `Content-Type`: `application/json`
     - `X-Secret-Key`: `<ваш_SECRET_KEY>`
   - **Тело запроса (Request Body)**: `JSON`
     - Ключ `text` со значением: выберите переменную **«Продиктованный текст»**.
5. Добавьте действие: **«Получить значение словаря»** (Get Dictionary Value):
   - Ключ: `summary`
   - Из: `Содержимое URL`
6. Добавьте действие: **«Произнести текст»** (Speak Text):
   - Выберите значение из предыдущего шага.

🎯 **Результат:** Вы зажимаете кнопку действия или говорите: *«Привет, Siri, Секретарь»*, надиктовываете: *«Купил обед за 600 рублей и в список покупок минералку»*, и Siri голосом отвечает: *«Добавлен расход 600 ₽ на обед и покупка: минералка»*!

## 🔒 Безопасность

- База данных SQLite хранится локально на вашем компьютере.
- Текстовые поля (названия, комментарии, описания) автоматически шифруются ключом Fernet перед записью на диск.
- Все API-запросы проверяют `SECRET_KEY`.

## 🛡️ Безопасное обновление и откат изменений (Backup & Rollback)

В проект встроена система автоматического резервного копирования и защиты от ошибок:

### 1. Безопасное сохранение на GitHub:
Перед каждой отправкой кода на GitHub запускается проверка синтаксиса и создаётся резервная копия базы данных и `.env`:
```bash
./save.sh "описание ваших изменений"
```
* **Защита от сбоев:** если в коде есть ошибка, скрипт остановит отправку и не допустит поломки на GitHub.
* **Резервная копия:** база `secretary.db` и `.env` автоматически сохраняются в папку `backups/backup_ДАТА/`.
* **Контрольная точка:** на GitHub создаётся тег `checkpoint_ДАТА`.

### 2. Мгновенный откат при необходимости:
Если после изменений что-то сломалось или вы хотите вернуться к предыдущей рабочей версии:
```bash
./rollback.sh
```
Скрипт предложит откатить код назад на один шаг и (по желанию) восстановить базу данных из резервной копии.
